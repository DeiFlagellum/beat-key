# Security policy

beat-key must release a share only once its beat has arrived. A way to obtain a share earlier,
to read or derive the private key, or to make the server sign anything else is a
vulnerability. Please report it privately by e-mail to **kontakt@advena-partners.com**
(English, German or Polish), as listed in <https://sigelith.org/.well-known/security.txt>, and
do not open a public issue for it.

Fixes are released as a new image; only the latest release is supported. The digest of each
release image is pinned in the [README](README.md), so operators can check what they run.
